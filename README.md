# Earn to Die 2 - UI/UX Redesign

A comprehensive UI/UX optimization project for *Earn to Die 2*, conducted as part of an Applied Human-Computer Interaction (AHCI) study. This project focuses on identifying usability bottlenecks and implementing a refined interface to reduce cognitive load.

##  Project Overview
The objective of this project was to perform a deep-dive **Heuristic Evaluation** on the existing game interface and implement a cleaner, more intuitive design. By applying HCI principles, the goal was to decrease cognitive load and streamline the user journey.

##  Methodology & Tools
- **Heuristic Evaluation:** Audited the game interface based on Nielsen’s Ten Usability Heuristics.
- **Tooling:** Implemented the redesign using **Google Stitch**.
- **Focus Area:** Reducing visual clutter and improving navigation hierarchy.

##  Key Improvements
- **Cognitive Load Reduction:** Simplified the HUD (Heads-Up Display) and menu navigation to allow players to focus on core gameplay mechanics.
- **Heuristic Alignment:** Resolved high-severity usability issues identified during the initial audit.
- **Visual Hierarchy:** Streamlined UI elements to provide clearer feedback and accessibility.
